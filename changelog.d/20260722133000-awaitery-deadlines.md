Integrate `awaitery@1.0.19` for cooperative HTTP retry delays, per-attempt deadlines, and WebSocket readiness/request controls. HTTP cancellation now consistently surfaces `SnapReqAbortError`, HTTP timeouts retain `SnapReqTimeoutError` metadata, owned request/response resources are torn down, and WebSocket failures intentionally surface the exact `signal.reason` or raw `TimeoutError` while timeouts remove only the affected pending operation and preserve existing call forms and defaults.
